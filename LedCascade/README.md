# Описание задания

## Цель:
Написать программу, которая управляет пятью светодиодами, подключёнными к одному порту микроконтроллера (например, PORTB0–PORTB4).
Каждый светодиод должен мигать (переключаться) с разным периодом, задаваемым через константы.


## Задача
Дан пример кода (см. blink.ipynb), в котором один светодиод мигает с использованием прерываний по переполнению таймера Timer1.
Необходимо расширить эту логику, чтобы управлять пятью светодиодами, каждый из которых мигает с разной частотой.

Период мигания каждого светодиода должен определяться как целое число временных интервалов, задаваемых таймером.
Частоту таймера или задержку напрямую указывать нельзя — нужно использовать периодические прерывания для отслеживания прошедших интервалов.

## Требования:

* нельзя использовать функции `delay()` или `millis()`;
настройка пинов должна выполняться через регистры `DDRx`, `PINx`, `PORTx` (без `pinMode()`, `digitalRead()`, `digitalWrite()` и т. п.);

* нельзя жёстко задавать периоды мигания — они должны выражаться как целое кратное минимальной единице времени;

* используется один таймер для всех пинов;
необходимо применять побитовые операторы (`|`, `&`, `>>` и т. д.) для изменения состояния регистров;

* прерывания таймера должны происходить точно по времени, с разрешением 1/16000000 секунды, без приблизительных задержек.

# Описание решения

### Константы и определения
В коде используются макросы для пинов (`PB0–PB4`) и константы, определяющие, сколько базовых интервалов должно пройти до переключения каждого светодиода:

```cpp
// --- Константы для пинов ---
#define LED1_PIN PB0 // Пин 8
#define LED2_PIN PB1 // Пин 9
#define LED3_PIN PB2 // Пин 10
#define LED4_PIN PB3 // Пин 11
#define LED5_PIN PB4 // Пин 12

// --- Константы для периодов ---
const uint8_t PERIOD_LED1 = 1; // 250 мс
const uint8_t PERIOD_LED2 = 2; // 500 мс
const uint8_t PERIOD_LED3 = 3; // 750 мс
const uint8_t PERIOD_LED4 = 4; // 1000 мс
const uint8_t PERIOD_LED5 = 5; // 1250 мс
```

### Функция setup()

#### Timer1 для базового интервала (250 мс)

Таймер настроен в режиме CTC (Clear Timer on Compare Match) для генерации точного прерывания каждые 250 миллисекунд.

* Сброс прерываний: `cli()` отключает прерывания.

* Регистр `OCR1A`: Установлен в значение `15624`.

* Делитель (Prescaler): Установлен в 256 (`CS12`).

* Настройка пинов: Пины PB0-PB4 настроены как выходы (`DDRB |= ...`) с использованием побитовых операторов и установлены в LOW (`PORTB &= ~...`).

* Включение прерываний: `sei()` разрешает прерывания.

#### Обработчик прерывания ISR

```cpp
ISR(TIMER1_COMPA_vect) {
    // ... 
}
```

Обработчик прерывания вызывается каждые 250 мс. Внутри него реализована логика управления каждым светодиодом независимо, с использованием отдельных статических счетчиков (`static uint8_t counter_ledx`).

1. Инкремент: На каждом вызове счетчик соответствующего светодиода увеличивается на 1.

2. Проверка: Если счетчик достиг значения константы `PERIOD_LEDx` (целевого множителя):

    * Состояние пина инвертируется побитовой операцией XOR: `PORTB ^= (1 << LEDx_PIN)`;

    * Счетчик сбрасывается: `counter_ledx = 0`;

Этот подход гарантирует, что каждый светодиод переключается ровно через заданное кратное базового интервала (250 мс).

# Результат работы

Светодиоды переключают свое состояние (изменение HIGH/LOW) со следующими интервалами:

| Светодиод | Множитель (PERIOD_LEDx) | Интервал переключения | Полный период мигания (ВКЛ/ВЫКЛ) |
|-----------|------------------------|----------------------|----------------------------------|
| LED 1     | 1                      | 1 × 250 мс = 250 мс  | 500 мс (0.5 сек)                |
| LED 2     | 2                      | 2 × 250 мс = 500 мс  | 1000 мс (1.0 сек)               |
| LED 3     | 3                      | 3 × 250 мс = 750 мс  | 1500 мс (1.5 сек)               |
| LED 4     | 4                      | 4 × 250 мс = 1000 мс | 2000 мс (2.0 сек)               |
| LED 5     | 5                      | 5 × 250 мс = 1250 мс | 2500 мс (2.5 сек)               |


Вся логика выполняется в прерывании, а функция loop() остается пустой.
