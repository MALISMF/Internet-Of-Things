# Управление семисегментным индикатором через каскадное соединение сдвиговых регистров

Данное решение реализует секундный счетчик (от 00 до 59) с выводом на два семисегментных индикатора через каскад из двух сдвиговых регистров 74HC595.

## Архитектура решения
*   **Микроконтроллер:** ATmega328P (Arduino Uno/Nano).
*   **Метод расширения портов:** Каскадирование сдвиговых регистров (SISO).
*   **Взаимодействие:** Неблокирующий ввод через последовательный порт (Serial Interface).
*   **Управление временем:** 1000 мс через прерывание аппаратного таймера Timer1.
*   **Управление портами:** Прямая манипуляция регистрами ввода-вывода (AVR Port Manipulation) для максимального быстродействия.

## Ключевые компоненты решения

### 1. Управление сдвиговыми регистрами (Shift Registers)
Вместо стандартной функции `shiftOut()`, решение использует прямой доступ к порту **PORTB** (пины 10, 11, 12). Это обеспечивает выполнение без блокировок и минимальные накладные расходы.

```cpp
// Передача данных в каскад регистров
for (int n = 0; n < 2; n++) { 
    uint8_t digitId = nums[n];
    for (int i = 0; i < 8; i++) {
        bool bitValue = digits[digitId][i];
        if (COMMON_CATHODE == false) bitValue = !bitValue;

        // Прямая манипуляция битами порта PORTB (регистры вывода)
        if (bitValue) PORTB |= (1 << 2);  // Data HIGH (Pin 10)
        else PORTB &= ~(1 << 2);         // Data LOW (Pin 10)
    
        PORTB |= (1 << 3);               // Clock HIGH (Pin 11)
        PORTB &= ~(1 << 3);              // Clock LOW (Pin 11)
    }
}
```

### 2. Аппаратный таймер (Timer1)
Для обеспечения идеальной точности в 2025 году используется Timer1 в режиме CTC (Clear Timer on Compare Match).
Это гарантирует стабильный инкремент счетчика раз в секунду независимо от работы основного цикла.

```cpp
// Настройка таймера в блоке setup()
cli(); // Отключение прерываний на время настройки
TCCR1A = 0; TCCR1B = 0; TCNT1 = 0;
OCR1A = 62499;            // Интервал 1 секунда при тактовой частоте 16 МГц
TCCR1B |= (1 << WGM12);    // Включение режима CTC
TCCR1B |= (1 << CS12);     // Установка предделителя 256
TIMSK1 |= (1 << OCIE1A);   // Разрешение прерывания по совпадению
sei(); // Включение прерываний
```
### 3. Обработка данных (Serial)
Основной цикл loop() работает в неблокирующем режиме.
Синхронизация данных между прерыванием и циклом реализована через временную остановку прерываний.

```cpp
if (Serial.available() > 0) {
    int input = Serial.parseInt();
    if (input >= 0 && input <= 59) {
        cli(); 
        counter = (uint8_t)input;
        updateDisplay();
        sei();
    }
}
```

### 4. Конфигурация индикатора
Флаг COMMON_CATHODE выведен в начало.
Это позволяет мгновенно адаптировать код под индикаторы с общим анодом или общим катодом без изменения таблицы сегментов.

```
const bool COMMON_CATHODE = true; 

if (COMMON_CATHODE == false) {
    bitValue = !bitValue; 
}
```

### 5. Схема соответствия битов
Массив digits[10][8] хранит состояния сегментов для каждой цифры.
Структура массива соответствует физическому подключению сегментов к выходам сдвигового регистра в порядке: A, B, C, D, E, F, G, DP.

| Индекс  | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|--------:|---|---|---|---|---|---|---|---|
| Сегмент | A | B | C | D | E | F | G | DP |
